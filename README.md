# Profil de base HTML/CSS 25/26

Objectif
- Faire une page de présentation simple, propre et responsive.

Contenu de la page
- Header: avatar + nom/pseudo.
- Main: paragraphe de présentation, liste de liens préférés, vidéo YouTube.
- Footer: une devise.

HTML
- Structure sémantique: header, main, footer, section.

CSS
- Polices Google Fonts: Bitcount Grid Single (titres), Momo Trust Sans (texte).
- Palette cohérente (sombre).
- Avatar redimensionné et arrondi (object-fit: cover).
- Vidéo responsive via un wrapper (.video-wrap, aspect-ratio: 16/9, overflow: hidden).
- Liens avec hover. Layout centré (max-width + margin: 0 auto).

Arborescence
- index.html
- style.css
- img/ma_photo.jpeg

Bonnes pratiques
- Liens externes: target="_blank" rel="noopener".
- Teste avec “Go Live” (VS Code).
